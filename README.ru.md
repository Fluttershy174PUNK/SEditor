# SEditor

Лёгкий редактор блок-схем, архитектурных карт и диаграмм проекта в переносимом HTML-файле. Откройте `SEditor.html` в браузере — установка и сервер не нужны.

[English README](README.md) · [Формат схемы](docs/schema-format.md) · [SEskill](https://github.com/Fluttershy174PUNK/SEskill)

## Открыть и передать схему

Откройте JSON кнопкой **Открыть** или перетащите файл на страницу. Кнопка **HTML** скачивает переносимую копию редактора с текущей схемой внутри. Такой файл можно перемещать и передавать другим.

## Возможности

- Фигуры, надписи, таблицы, зоны, уровни и стадии
- Связи с редактируемыми подписями, маршрутом и стрелками
- Множественное выделение; `Ctrl/Cmd+C/V/X/Z` — копировать, вставить, вырезать и отменить для одного или нескольких выбранных узлов
- 16 приглушённых цветов заливки, редактируемые подписи и описания
- Экспорт JSON и PNG, сетка и привязка, панорамирование и зум
- Русский и английский интерфейс

## Файлы и приватность

Открывайте JSON системным диалогом браузера. В поддерживаемых Chromium-браузерах редактор может сохранять прямо в выбранный файл и показывать недавние файлы, если браузер разрешает сохранять их дескрипторы. Разрешения на файлы контролирует браузер. В остальных браузерах используются скачивания. Сервер не нужен. В HTML-ярлыках и некоторых браузерах прямой доступ к файлам и список недавних файлов могут быть недоступны.

## Совместимость JSON

Актуальная версия схемы — v1. Старые схемы без версии и схемы v1 открываются; неизвестные будущие версии отклоняются, чтобы не потерять данные. При сохранении значения по умолчанию и вычисляемые поля опускаются. Подробности — в [описании формата](docs/schema-format.md).

## Разработка

Требуется Node.js 18+.

```bash
npm ci
npm run build
npm test
```

Редактируйте `src/`; сборка создаёт корневой `SEditor.html` и обновляет копию для управляемого runtime скилла. `app/version.json` хранит контрольные суммы.
