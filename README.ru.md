# SEditor

Лёгкий редактор блок-схем, архитектурных карт и диаграмм проекта в одном HTML-файле. Откройте `app/editor.html` в браузере — установка и сервер не нужны.

[English README](README.md) · [Формат схемы](docs/schema-format.md) · [SEskill](https://github.com/Fluttershy174PUNK/SEskill)

## Открыть схему

Откройте парный HTML-ярлык рядом с JSON. Ярлык содержит схему внутри и работает через `file://`. После изменения JSON ярлык нужно пересоздать:

```bash
cd app
node create-shortcut.mjs ../example_scheme/example-flow.json
```

## Возможности

- Фигуры, надписи, таблицы, зоны, уровни и стадии
- Связи с редактируемыми подписями, маршрутом и стрелками
- Множественное выделение, копирование/вставка/вырезание, undo/redo и порядок слоёв фигур
- 16 приглушённых цветов заливки, редактируемые подписи и описания
- Экспорт JSON и PNG, сетка и привязка, панорамирование и зум
- Русский и английский интерфейс

## Необязательный локальный сервер

Backend без дополнительных runtime-зависимостей добавляет список недавних схем, прямую запись файлов и создание ярлыка из редактора:

```bash
node app/server.js  # http://127.0.0.1:5174/editor.html
```

Оставляйте `HOST=127.0.0.1`: файловый API может обращаться к произвольным локальным путям. Без сервера редактор также умеет сохранять в выбранную пользователем папку в поддерживаемых браузерах.

## Совместимость JSON

Актуальная версия схемы — v1. Старые схемы без версии и схемы v1 открываются; неизвестные будущие версии отклоняются, чтобы не потерять данные. При сохранении значения по умолчанию и вычисляемые поля опускаются. Подробности — в [описании формата](docs/schema-format.md).

## Разработка

Требуется Node.js 18+.

```bash
npm ci
npm test
npm run build
```

Редактируйте `src/`; `npm run build` собирает самодостаточный `app/editor.html`. Версия рантайма и контрольные суммы находятся в `app/version.json`.
